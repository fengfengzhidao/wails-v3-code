# 第 5 章练习指南 · 学会够用的网页基础

本章围绕一个问候页面，练习 HTML 结构、CSS 外观和 JavaScript 交互。问候由当前页面中的 JavaScript 生成，后续章节再连接 Go 服务。

## 1. 从完整页面开始

用编辑器打开本章目录。进入 `examples`，用浏览器打开 `playground.html`。

1. 在姓名框输入 `小明`。
2. 点击“打招呼”。
3. 结果段落显示 `你好，小明`。
4. 把姓名改成几个空格，再点击。
5. 结果显示 `请先输入姓名`。

修改网页后，先保存文件，再刷新浏览器。

本次浏览器验证通过本地 HTTP 地址完成。如果想按同样方式运行，先确认已经安装 Python，并在本章的 `examples` 目录执行。

```powershell
python -m http.server 8055 --bind 127.0.0.1
```

浏览器打开以下地址。

```text
http://127.0.0.1:8055/playground.html
```

结束练习后，在运行服务的终端按 `Ctrl+C`。

## 3. HTML 把内容组织起来

```html
<h1>我的第一个交互页面</h1>
<label for="name">姓名</label>
<input id="name" placeholder="请输入姓名">
<button id="greet" type="button">打招呼</button>
<p id="result" role="status"></p>
```

`h1` 是主要标题，`input` 提供单行输入，`button` 提供按钮，`p` 显示结果。`label` 的 `for` 与输入框的 `id` 对应，为它提供名称。同一页面中的 `id` 应当唯一。[HTML 入门](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content)、[label 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/label)

需要多行输入时使用 `textarea`。对应练习位于 `textarea.html`。

```html
<label for="content">内容</label>
<textarea id="content" rows="4" cols="30"></textarea>
```

文档头部用 `<meta charset="UTF-8">` 声明字符编码，页面展示的控件放在 `body` 内。完整示例还包含页面标题和视口设置。

## 4. CSS 选择元素并设置外观

在 `style` 标签内修改按钮的规则。

```css
button {
    background: #2563eb;
    color: white;
    border-radius: 8px;
    padding: 8px 16px;
}
```

`button` 是选择器，花括号中写属性和值。`padding` 是内容到边框之间的内边距，`margin` 是边框外的间隔，`border-radius` 控制圆角。试着修改背景色和内边距，保存并刷新页面，观察变化。[CSS 盒模型](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model)

完整示例还设置了字体、内容宽度、输入框样式和按钮边框，便于阅读与操作。

## 5. 找到元素，再注册点击处理函数

下面是 `playground.html` 中完整的交互脚本。它放在控件后面的 `script` 标签里。

```javascript
const nameInput = document.getElementById("name");
const result = document.getElementById("result");
const button = document.getElementById("greet");

button.addEventListener("click", () => {
    const name = nameInput.value.trim();
    result.textContent = name ? `你好，${name}` : "请先输入姓名";
    console.log("按钮被点击了");
});
```

`document.getElementById` 根据标识取得元素。`addEventListener` 注册事件处理函数，按钮被点击时执行其中的回调。示例中的脚本位于控件后面，使浏览器先解析控件，再运行查找语句。[事件监听文档](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener)

`value` 读取输入框当前的内容，`trim()` 返回去掉首尾空白后的新字符串。因此读取输入的语句放在点击处理函数内，每次点击都会读取当时的值。[trim 文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/trim)

模板字符串用反引号包围，`${name}` 在生成文字时插入变量的值。`name ? A : B` 在本例中根据字符串是否非空选择结果。`textContent` 把结果作为文字放入段落。[textContent 文档](https://developer.mozilla.org/en-US/docs/Web/API/Node/textContent)

`console.log` 把调试信息写入浏览器开发者工具的控制台。点击按钮后，可以在控制台查找“按钮被点击了”。

## 6. 区分 const 和 let

```javascript
const button = document.getElementById("greet");
button.textContent = "再次打招呼";

let count = 0;
count = count + 1;
```

`const` 限制的是变量绑定的重新赋值，指向对象的属性仍可以修改。需要给变量重新赋值时，可以使用 `let`。[const 文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/const)

上面的按钮文字修改片段用于理解属性更新，按需放入完整示例的脚本中练习。

## 7. 导入一个本地模块

本章的模块例子包含三个文件。

```text
modules/
  index.html
  main.js
  greetservice.js
```

`greetservice.js` 导出 `Greet`，`main.js` 导入并调用它。

```javascript
import { Greet } from "./greetservice.js";
```

HTML 则以模块方式加载 `main.js`。

```html
<script type="module" src="./main.js"></script>
```

本例的路径对应代码包中实际存在的文件。后续 Wails 项目会使用其生成的绑定路径。模块练习通过前面的本地 HTTP 服务访问。[import 文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import)

## 8. 先练习 Promise、await 和错误处理

配套 `Greet` 是一个本地 JavaScript 异步模拟函数，延迟约 600 毫秒后返回问候或拒绝空白姓名。页面已经标出“本地异步模拟”。

Promise 代表异步操作的最终完成或失败，具有等待、成功和失败状态。在 `async` 函数里用 `await` 等待结果，调用拒绝时通过 `catch` 处理错误。`await` 暂停的是当前异步函数的后续执行，浏览器可以继续处理其他任务。[Promise 文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise)、[await 文档](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/await)

模块示例中的实际点击处理如下，元素引用已在文件前面定义。

```javascript
button.addEventListener("click", async () => {
    button.disabled = true;
    result.textContent = "正在等待结果…";
    try {
        const message = await Greet(nameInput.value);
        result.textContent = message;
    } catch (error) {
        result.textContent = error.message;
    } finally {
        button.disabled = false;
    }
});
```

等待时禁用按钮，完成后通过 `finally` 恢复操作。输入 `小明` 得到问候，输入空白得到 `请输入姓名`。真正的 Go 服务注册和前端绑定在后续章节完成。
