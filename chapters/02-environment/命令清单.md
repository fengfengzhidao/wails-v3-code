# 第 2 章命令清单

课程按 Windows 和 PowerShell 为主线，固定 Wails v3.0.0。资料核对日期为 2026 年 11 月 10 日。

## 官方下载入口

- Go 选择当前维护的补丁版本，要求工具链至少为 1.26。[Go 下载](https://go.dev/dl/)
- Node.js 选择当前受支持的 LTS，安装器通常包含 npm。[Node.js 下载](https://nodejs.org/en/download)
- 使用代码编辑器打开项目文件夹。[VS Code 下载](https://code.visualstudio.com/Download)
- Windows 使用 WebView2 Runtime 显示应用内网页，缺失时安装 Evergreen Runtime。[WebView2 下载](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

Go 版本和平台依赖依据 Wails v3 官方安装说明。[Wails 安装指南](https://v3.wails.io/quick-start/installation/)

## 检查工具版本

```powershell
go version
node --version
npm.cmd --version
```

安装程序结束后，重新打开 PowerShell，再执行检查命令。

## 安装 Wails CLI 并检查环境

```powershell
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
wails3 doctor
```

第一次安装会下载依赖并编译，等待命令结束。根据 `doctor` 的具体报告补齐当前平台所需依赖，再重新检查。[Wails v3.0.0 发布与安装](https://github.com/wailsapp/wails/releases/tag/v3.0.0)

## 定位命令安装目录

```powershell
go env GOBIN
go env GOPATH
Get-Command wails3 -ErrorAction SilentlyContinue
```

显式设置了 `GOBIN` 时，按该目录查找工具。默认情况下，工具位于 `GOPATH` 下的 `bin` 目录。

```text
C:\Users\YourName\go\bin
```

`YourName` 代表实际 Windows 用户名。在 Windows 搜索中打开账户环境变量，编辑用户 `Path`，加入实际工具目录。保存后重新打开终端。

默认工具目录也可以通过完整路径验证。

```powershell
& "$env:USERPROFILE\go\bin\wails3.exe" doctor
```

自定义目录需要按实际位置修改。Go 工具路径与终端重启说明可参照官方安装指南。[Go 安装说明](https://go.dev/doc/install)

## npm.ps1 执行策略提示

Windows PowerShell 中可通过 Node.js 安装包提供的 `npm.cmd` 入口检查 npm。

```powershell
npm.cmd --version
```

## macOS 补充

```bash
xcode-select --install
```

## Ubuntu 24.04+ / Debian 13+ 补充

```bash
sudo apt update
sudo apt install build-essential pkg-config \
  libgtk-4-dev libwebkitgtk-6.0-dev
```

其他发行版按官方对应条目准备依赖，安装后运行 `wails3 doctor`。[Wails 平台依赖](https://v3.wails.io/quick-start/installation/)

## 本章完成标准

- Go、Node.js 和 npm 能返回版本号。
- 编辑器能打开整个项目文件夹。
- Wails CLI 可以运行。
- `wails3 doctor` 确认基础桌面开发环境就绪。

视频中的安装卡片、终端提示和版本输出均已标注为示意，具体版本号与诊断结果按自己的电脑确认。
