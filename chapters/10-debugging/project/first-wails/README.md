# 第 10 章健康调试工程

本工程包含问候与本地便笺功能，并在前端查找保存按钮、Go 加载便笺的位置加入日志。

在项目根目录运行。

```powershell
wails3 dev
```

如需指定可用开发端口，可运行 `wails3 dev -port 9246`。

在开发窗口右键选择“检查”，再进入 Console，核对按钮查找结果与具体错误。Go 加载步骤会在终端记录“开始加载便笺”。

故障副本与修复对照位于[本章 labs](../../labs)，操作步骤见[本章练习指南](../../练习指南.md)。本目录的 HTML ID 与绑定导入路径已经修复，保存功能已实测通过。
