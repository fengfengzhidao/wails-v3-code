# 第 7 章练习指南 · 实战，制作本地便笺

本章接着第 6 章的 `first-wails` 项目，加入一个便笺服务，让界面可以读取本地文字、提交保存，并在重新打开时恢复最后保存的内容。

## 1. 文件修改顺序

先在开发终端按 `Ctrl+C`，停止开发命令。按配套项目中的完整内容逐个处理文件。

| 文件 | 本章操作 |
| --- | --- |
| `greetservice.go` | 沿用第 6 章的中文问候与输入检查 |
| `noteservice.go` | 新建便笺服务 |
| `main.go` | 注册两个服务，准备资源和窗口 |
| `frontend/index.html` | 加入便笺编辑区、保存按钮、状态与路径 |
| `frontend/public/style.css` | 设置卡片、输入区、按钮与焦点样式 |
| `frontend/src/main.js` | 组织初始化、输入与保存处理 |

完整 Go、HTML、CSS 和 JavaScript 内容都在项目示例包中。对应的逐文件代码也保存在整套学习文档第 7 章。

## 2. 便笺服务的三个方法

| 方法 | 作用 | 返回结果 |
| --- | --- | --- |
| `Load()` | 读取已保存的文字 | `(string, error)` |
| `Save(text string)` | 保存本次提交的文字 | `error` |
| `FilePath()` | 返回数据文件位置 | `string` |

服务实例先在 Go 入口中创建，再注册到应用的 `Services`。前端通过自动生成的绑定调用这些方法。[Wails 服务说明](https://v3.wails.io/features/bindings/services/)

`NewNoteService` 通过 `os.UserConfigDir()` 取得当前用户的配置目录，在其中建立 `WailsLearningNote` 文件夹，再使用 `note.txt` 保存内容。页面底部会显示实际路径。[UserConfigDir 文档](https://pkg.go.dev/os#UserConfigDir)

## 3. 读取方法怎样处理第一次启动

`Load` 先取得互斥锁，再读取目标文件。文件尚不存在时返回空文本，其他读取错误则返回给前端。

```go
content, err := os.ReadFile(s.path)
if errors.Is(err, os.ErrNotExist) {
    return "", nil
}
if err != nil {
    return "", fmt.Errorf("读取便笺失败 %w", err)
}
return string(content), nil
```

完整方法还包含取得锁与释放锁的代码。路径来自服务实例，读取到的字节转成字符串交给界面。[ReadFile 文档](https://pkg.go.dev/os#ReadFile)

## 4. 保存操作分成几步

1. 在目标文件的同一目录创建临时文件。
2. 把本次提交的文字写进临时文件。
3. 检查写入和关闭结果。
4. 用临时文件替换目标 `note.txt`。
5. 成功时返回 `nil`，失败时返回包含操作上下文的错误。

临时路径通过 `defer os.Remove(tempPath)` 安排清理。正常替换完成后，临时路径已经移走，清理操作不会影响目标文件。[CreateTemp 文档](https://pkg.go.dev/os#CreateTemp)、[Rename 文档](https://pkg.go.dev/os#Rename)

本例按单个应用实例使用。`sync.Mutex` 协调的是当前进程中的服务实例读写，多进程编辑需要单独协调。本实现采用同目录临时文件替换，文件替换在不同平台上的原子性与断电持久性属于另外的评估范围。

## 5. 入口、页面和样式

`main.go` 创建 `noteService` 并检查初始化错误，然后注册问候服务与便笺服务，设置前端资源，创建窗口并执行 `app.Run()`。

```go
Services: []application.Service{
    application.NewService(&GreetService{}),
    application.NewService(noteService),
},
```

这段代码位于 `application.Options` 配置中。完整入口见项目里的 `main.go`。

页面中的编辑区和保存按钮，最开始都带有 `disabled`，读取完成后再由脚本启用。

```html
<textarea id="note" rows="10" disabled></textarea>
<button id="save-button" type="button" disabled>保存便笺</button>
<span id="note-status" role="status">正在加载</span>
<code id="file-path"></code>
```

样式用两个卡片区分问候和便笺，统一字体、边距和圆角，并为键盘焦点提供轮廓。

## 6. 前端初始化

脚本导入 Wails 运行时和服务绑定。

```javascript
import "@wailsio/runtime";
import { GreetService, NoteService } from "../bindings/example.com/learn/first-wails/index.js";
```

这个路径对应本课程的模块名。使用其他模块名时，按 `frontend/bindings` 中实际生成的结构调整。[Go 方法绑定说明](https://v3.wails.io/features/bindings/methods/)

初始化函数通过 `Promise.all` 等待两项独立结果。

```javascript
const [text, path] = await Promise.all([
    NoteService.Load(),
    NoteService.FilePath(),
]);
```

读取成功后，把文字放进编辑区，用 `savedText` 记录已保存基准，再显示路径并启用编辑和保存。读取失败时，状态显示加载错误，控件继续保持初始禁用状态。

## 7. 输入与保存状态

输入变化时比较当前内容与 `savedText`。

```javascript
noteStatus.textContent = noteInput.value === savedText
    ? "所有修改已保存"
    : "有未保存的修改";
```

保存时先取得点击瞬间的快照。

```javascript
const textToSave = noteInput.value;
saveButton.disabled = true;
noteStatus.textContent = "正在保存";

await NoteService.Save(textToSave);
savedText = textToSave;
```

成功后，再比较编辑区是否仍与本次快照一致。一致就显示 `保存成功`，保存期间又输入了内容，则显示 `已保存刚才的内容，当前还有新的修改`。

保存失败通过 `catch` 显示错误，只有成功调用会推进 `savedText`。`finally` 恢复保存按钮。问候表单也会把 Go 返回的输入错误显示到页面上。

## 8. 生成绑定并启动

在项目根目录执行。

```powershell
gofmt -w main.go greetservice.go noteservice.go
wails3 generate bindings
wails3 dev
```

生成成功后，可在以下目录找到 `index.js` 和两个服务文件。

```text
frontend/bindings/example.com/learn/first-wails/
```

示例包附有 `frontend/dist/index.html` 启动占位文件，供首次生成绑定时满足 Go 嵌入路径。开发和构建任务会把它更新为实际前端产物。

从本章目录进入 `project/first-wails` 执行命令。工具准备步骤见第 2 章。

## 9. 按顺序验收

| 操作 | 预期结果 |
| --- | --- |
| 输入 `小明` 并问候 | 显示 Go 返回的中文问候 |
| 姓名只有空白并问候 | 显示 `请输入姓名` |
| 在便笺中输入中文和多行文字 | 显示 `有未保存的修改` |
| 点击保存 | 显示成功，或指出保存期间还有新修改 |
| 修改后再次保存 | 同一个数据文件被更新 |
| 关闭并重新启动 | 读回最后保存的内容 |
| 清空、保存并重新启动 | 正常读回空文本 |
| 编辑后直接关闭 | 下次读取仍来自最后保存的文件 |

本章采用点击保存的交互。关闭前查看状态，并按需要保存。可以把关闭前提醒作为后续扩展练习。
