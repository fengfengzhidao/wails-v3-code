# 第 9 章桌面扩展实验

本工程把时间事件、窗口标题、文件选择和生命周期日志合并到便笺应用中。

## 运行

在此项目根目录执行。

```powershell
wails3 dev
```

启动时会打开系统文件选择框，初始位置是本项目的 `fixtures`。选择 `sample-note.txt` 后，Go 日志会打印路径。也可以取消本次选择，再查看窗口里的时间段落和标题。

正常退出应用，终端会显示服务退出日志。Windows 版 v3.0.0 的取消选择通过错误返回，本工程先处理错误，再检查空路径。

## 代码位置

- `main.go` 注册 Go 时间请求与应用启动事件，创建文件选择框，并注册演示服务。
- `lifecycleservice.go` 用日志演示服务启动和退出方法。
- `frontend/index.html` 提供显示时间的段落。
- `frontend/src/main.js` 注册事件监听，发送一次时间请求，并设置当前窗口标题。

完整步骤与验收表见[本章练习指南](../../练习指南.md)。
