# 第 4 章练习指南 · 学会够用的 Go

本章使用 Windows 和 PowerShell，接着上一章的学习目录练习。Go 已按第 2 章安装完成，命令 `go version` 应能显示版本。

## 1. 从头建立练习项目

先进入自己的学习目录。例如上一章选择了 `C:\dev\wails-learning`，就执行以下命令。

```powershell
Set-Location C:\dev\wails-learning
New-Item -ItemType Directory -Path go-basics
Set-Location go-basics
go mod init example.com/learn/go-basics
```

如果已经创建过 `go-basics`，直接进入它。如果当前目录已经有 `go.mod`，继续写代码即可。`go mod init` 在当前目录建立模块，模块文件记录模块路径等信息。这里的示例域名可以用于本地学习，无须注册或访问。[Go 入门教程](https://go.dev/doc/tutorial/getting-started)

在编辑器中打开 `go-basics`，新建 `main.go`，使用 UTF-8 编码保存下面的完整代码。

```go
package main

import "fmt"

func main() {
    name := "小明"
    fmt.Println("你好，" + name)
}
```

在包含 `main.go` 和 `go.mod` 的目录执行。

```powershell
go run .
```

预期输出为 `你好，小明`。点表示当前目录中的包。`main` 包中的 `main` 函数是本例程序的入口，`fmt.Println` 输出一行文字。[Go 入门教程](https://go.dev/doc/tutorial/getting-started)

## 3. 变量与类型

下面的片段写在 `main` 函数内部。

```go
var title string = "我的便笺"
count := 3
saved := true
fmt.Println(title, count, saved)

name := "小明"
name = "小红"
fmt.Println("你好，" + name)
```

`string` 保存字符串，`int` 常用于整数，`bool` 有 `true` 和 `false` 两种值。`:=` 在函数内部声明并初始化变量，示例中的类型由初始值推断。对已有变量重新赋值使用 `=`。Go 编译器会检查局部变量是否被使用。[Go 语言规范](https://go.dev/ref/spec#Variable_declarations)

## 4. 函数的输入和输出

把函数定义写在 `main` 函数外面。

```go
func greet(name string) string {
    return "你好，" + name
}
```

调用代码写在 `main` 函数里面。

```go
message := greet("小明")
fmt.Println(message)
```

`name string` 声明输入参数，右侧的 `string` 声明返回值类型，`return` 把结果交回调用位置。[Go 函数声明](https://go.dev/ref/spec#Function_declarations)

## 5. 亲手触发错误分支

打开 `examples/04-errors/main.go`。先运行现有代码，确认输出正常问候。然后把这一行中的输入改成只有空格的字符串。

```go
message, err := greet("   ")
```

保存并重新运行，预期输出为 `操作失败 请输入姓名`。

完整程序如下。

```go
package main

import (
    "fmt"
    "strings"
)

func greet(name string) (string, error) {
    name = strings.TrimSpace(name)
    if name == "" {
        return "", fmt.Errorf("请输入姓名")
    }
    return "你好，" + name, nil
}

func main() {
    message, err := greet("   ")
    if err != nil {
        fmt.Println("操作失败", err)
        return
    }
    fmt.Println(message)
}
```

`strings.TrimSpace` 去掉字符串首尾空白。`(string, error)` 表示返回两个值。`err != nil` 检查是否存在错误，有错误时先处理，再通过 `return` 结束当前函数。[TrimSpace 文档](https://pkg.go.dev/strings#TrimSpace)、[返回和处理错误](https://go.dev/doc/tutorial/handle-errors)

调用和错误检查也可以合写。以下仅展示语法形状，`action` 代表一个实际返回 `error` 的函数。这里声明的 `err` 作用域在整个 `if` 语句内，包括它可能具有的 `else` 分支。[Go if 语句](https://go.dev/ref/spec#If_statements)

```go
if err := action(); err != nil {
    fmt.Println(err)
    return
}
```

## 6. 从结构体到服务方法

结构体把相关字段组合起来。

```go
type Note struct {
    Title string
    Saved bool
}
```

方法通过接收者附着在类型上。以下是完整的本地练习，也位于 `examples/06-service`。

```go
package main

import "fmt"

type GreetService struct{}

func (g *GreetService) Greet(name string) string {
    return "你好，" + name
}

func main() {
    service := &GreetService{}
    message := service.Greet("小明")
    fmt.Println(message)
}
```

`*GreetService` 是指向服务实例的指针，`&GreetService{}` 创建值并取得地址。`Greet` 以大写字母开头，是导出方法。Wails 可以为已注册服务中符合绑定规则的方法生成前端绑定，实际注册和界面调用在后续章节完成。[Go 方法声明](https://go.dev/ref/spec#Method_declarations)、[Wails 服务文档](https://v3.wails.io/features/bindings/services/)

## 7. 后续语法速查

| 写法 | 含义 |
| --- | --- |
| `[]string` | 字符串切片，可以理解为长度可变的列表 |
| `defer cleanup()` | 在当前函数返回前执行已安排的清理调用 |
| `fmt.Errorf("读取失败 %w", err)` | 给错误补充上下文，并保留原始错误关系 |
| `sync.Mutex` | 互斥锁，用于协调同一进程内对共享状态的并发访问 |

这些写法会在后续具体操作中展开。[Go 切片类型](https://go.dev/ref/spec#Slice_types)、[defer 语句](https://go.dev/ref/spec#Defer_statements)、[Errorf 文档](https://pkg.go.dev/fmt#Errorf)、[Mutex 文档](https://pkg.go.dev/sync#Mutex)
