### 12.3 练习一，显示字符数量

在 HTML 中加入计数元素，在文本框的 `input` 事件中更新计数。

提示如下。

```javascript
const count = Array.from(noteInput.value).length;
```

这里按 Unicode 码点计数。包含组合字符或多个码点构成的 emoji 时，显示字符数量可能与码点数量不同。

**完成标准**　输入、删除和粘贴文字时，计数都会更新。初始读取完成后也能显示正确数量。

### 12.4 练习二，添加 Ctrl+S 保存

监听 `keydown`，判断 Ctrl 或 macOS Command 与 S 的组合，阻止页面默认行为，再调用现有保存入口。保存按钮禁用时跳过触发。

**完成标准**　快捷键和点击按钮共用同一套保存逻辑，保存失败能够显示错误。

### 12.5 练习三，导入和导出

结合文件对话框和现有 Go 文件操作，增加导入与导出功能。

**完成标准**　取消对话框、读取失败、写入失败都有对应处理。导入前已有未保存内容时，能让用户决定如何处理。

### 12.6 练习四，升级为多条便笺

先定义包含 ID、标题和正文的数据结构，再设计新增、列表、修改和删除方法。数据量较小时可学习 JSON 文件存储，随后再学习 SQLite。

**完成标准**　重启后能恢复多条便笺，修改或删除一条时能准确对应到目标记录。

## 计数参考实现

在文本框后加入显示元素。

```html
<p id="character-count">字符计数（码点） —</p>
```

取得元素后，复用计数更新函数。

```javascript
const characterCount = document.getElementById("character-count");

function updateCharacterCount() {
    const count = Array.from(noteInput.value).length;
    characterCount.textContent = `字符计数（码点） ${count}`;
}
```

在已有 `input` 回调内调用该函数，接着执行原来的未保存状态判断。初始读取成功后，设置 `noteInput.value = text`，再调用该函数。具体位置见 `project/first-wails/frontend/src/main.js`。

字符串迭代按 Unicode 码点提供内容，`Array.from()` 可以将其收集成数组。以下两种带重音字母的表示可以帮助理解计数规则。[字符串迭代器](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String/Symbol.iterator)、[Array.from](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from)

```javascript
Array.from("").length;          // 0
Array.from("中文").length;      // 2
Array.from("A😀").length;       // 2
Array.from("e\u0301").length;  // 2，e 加组合重音符号
Array.from("\u00e9").length;   // 1，预组合的 é
```

视频图解用 `U+0065` 和 `U+0301` 表示两个输入码点，组合显示区域用预组合字形绘制外观。配套代码的验证输入使用 `e\u0301`。

## 保存快捷键参考实现

快捷键匹配后，检查保存按钮状态，再触发现有的点击入口。

```javascript
document.addEventListener("keydown", (event) => {
    const isSaveShortcut = (event.ctrlKey || event.metaKey)
        && !event.altKey && !event.shiftKey
        && event.key.toLowerCase() === "s";
    if (!isSaveShortcut) {
        return;
    }

    event.preventDefault();
    if (!saveButton.disabled) {
        saveButton.click();
    }
});
```

修饰键状态、默认行为处理与按钮点击分别对应这些浏览器 API。[ctrlKey](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/ctrlKey)、[metaKey](https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/metaKey)、[preventDefault](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault)、[click](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/click)

本次在 Windows 真实窗口中验证了 Ctrl+S。macOS Command 判断通过源码模拟检查，目标平台继续按相同步骤验收。
