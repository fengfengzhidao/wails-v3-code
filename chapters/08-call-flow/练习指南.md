# 第 8 章练习指南 · 读懂整个调用过程

本章沿着问候与保存的源码，理解界面事件、生成绑定、注册服务、Go 方法、返回结果和前端提示之间的联系。本章目录包含便笺工程、实际生成的绑定，以及一个独立的字段映射练习。

## 1. 先记住整条链路

1. 用户点击按钮，触发对应事件处理函数。
2. JavaScript 读取输入值，准备调用参数。
3. 前端调用生成的服务绑定函数。
4. 运行时根据绑定信息找到已注册的 Go 服务实例。
5. Go 执行对应方法。
6. 执行结果或错误交回 JavaScript。
7. 前端等待调用完成，再更新界面。

Wails 桥接机制把前端调用交给对应服务，再把结果交回前端。方法调用按异步 Promise 处理。[Go 与前端通信机制](https://v3.wails.io/concepts/architecture/)

## 2. 从问候表单进入 JavaScript

打开 `project/first-wails/frontend/src/main.js`，找到问候表单的处理函数。

```javascript
greetForm.addEventListener("submit", async (event) => {
    event.preventDefault();
    greetButton.disabled = true;

    try {
        greeting.textContent = await GreetService.Greet(nameInput.value);
    } catch (error) {
        greeting.textContent = describeError(error);
    } finally {
        greetButton.disabled = false;
    }
});
```

`submit` 事件进入异步处理函数。`preventDefault` 阻止默认表单提交，处理期间禁用按钮，最后恢复。传入的参数来自点击时的 `nameInput.value`。[表单提交事件](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/submit_event)

## 3. 找到实际生成的绑定

当前工程的绑定路径为。

```text
project/first-wails/frontend/bindings/example.com/learn/first-wails/
```

`index.js` 导出两个服务模块。进入 `greetservice.js`，可以看到当前版本生成的函数。

```javascript
export function Greet(name) {
    return $Call.ByID(1411160069, name);
}
```

这段代码把姓名参数交给运行时。方法编号来自工具生成的绑定信息。本项目使用 Wails v3.0.0，生成函数的类型为 `CancellablePromise<string>`，支持 `await` 与错误处理。阅读生成结果后，功能修改应在 Go 服务与前端源码中完成，再通过工具更新绑定。[方法绑定说明](https://v3.wails.io/features/bindings/methods/)

## 4. 对应到注册实例和 Go 方法

在 `main.go` 的应用配置里，找到服务注册。

```go
Services: []application.Service{
    application.NewService(&GreetService{}),
    application.NewService(noteService),
},
```

问候调用对应 `GreetService` 实例，读取和保存对应 `noteService` 实例。服务类型定义方法，注册过程把需要提供给前端的服务实例交给应用。[服务注册说明](https://v3.wails.io/features/bindings/services/)

再打开 `greetservice.go`。当前实际方法返回 `(string, error)`，先整理姓名，空白输入返回错误，正常输入返回问候与 `nil`。

```go
func (g *GreetService) Greet(name string) (string, error) {
    name = strings.TrimSpace(name)
    if name == "" {
        return "", fmt.Errorf("请输入姓名")
    }
    return "你好，" + name + "！欢迎学习 Wails v3。", nil
}
```

成功时 `await` 取得问候字符串，前端把它写入 `greeting.textContent`。Go 返回非空错误时，绑定调用拒绝，`catch` 负责显示错误，`finally` 恢复按钮。[返回值与错误处理](https://v3.wails.io/features/bindings/methods/)

## 5. 把同样的链路套到保存操作

回到前端源码，找到 `saveButton` 的点击处理函数。

```javascript
const textToSave = noteInput.value;
saveButton.disabled = true;
noteStatus.textContent = "正在保存";

try {
    await NoteService.Save(textToSave);
    savedText = textToSave;
    noteStatus.textContent = noteInput.value === savedText
        ? "保存成功"
        : "已保存刚才的内容，当前还有新的修改";
} catch (error) {
    noteStatus.textContent = `保存失败 ${describeError(error)}`;
} finally {
    saveButton.disabled = false;
}
```

`textToSave` 是本次点击的快照。生成的 `noteservice.js` 把它传给运行时，再执行 Go 中的 `Save`。

```javascript
export function Save(text) {
    return $Call.ByID(3103180052, text);
}
```

Go 执行同目录临时文件写入、关闭与替换操作。成功返回 `nil` 错误，前端等待调用正常完成，再推进基准与状态。当前生成绑定将成功结果标注为 `CancellablePromise<void>`。

成功提示由前端设置。失败时，Go 错误沿调用链返回，前端显示原因，再恢复按钮。原生运行结果可在第 7 章的验收视频中对应查看。

## 6. 对照三种返回方式

| Go 签名示意 | 前端等待后的结果 |
| --- | --- |
| `Greet(name string) string` | 成功取得字符串 |
| `Load() (string, error)` | 成功取得字符串，失败进入 `catch` |
| `Save(text string) error` | 成功完成调用，失败进入 `catch` |

表格第一行展示单一字符串返回的语法形状。本项目实际问候方法使用第 4 节展示的 `(string, error)`。

空字符串也可以是成功的读取结果。例如，清空便笺并保存后，`Load` 返回空文本和 `nil`，前端正常恢复为空编辑区。错误状态决定调用是否进入失败分支。[绑定返回与类型映射](https://v3.wails.io/features/bindings/methods/)

## 7. 理解共享服务实例

同一个应用中的窗口可以访问同一个已注册的服务实例。共享可变状态与需要协调的读写，要结合并发访问组织。便笺示例通过互斥锁协调当前进程内的读取与保存。[服务实例与并发示例](https://v3.wails.io/features/bindings/services/)

## 8. 独立练习结构体字段映射

配套 `examples/note-model` 是一个独立的 Go 控制台练习。它定义标题和正文，并输出 JSON。

```go
type Note struct {
    Title   string `json:"title"`
    Content string `json:"content"`
}
```

进入该目录运行。

```powershell
Set-Location .\examples\note-model
go run .
```

预期输出为。

```json
{
  "title": "学习笔记",
  "content": "今天读懂调用过程。"
}
```

`json` 标签控制序列化后的字段名，前端使用 `note.title` 与 `note.content` 读取对应内容。Wails 的结构体数据模型同样依据这些标签组织字段名。[数据模型说明](https://v3.wails.io/features/bindings/models/)

把便笺业务扩展成结构化模型时，同时调整服务参数或返回类型、前端字段访问，并重新生成绑定，再验证实际调用。

```powershell
wails3 generate bindings
```
