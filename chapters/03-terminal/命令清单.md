# 第 3 章命令清单 · 第一次使用终端

本章以 Windows 和 PowerShell 为主线。画面路径是学习示例，选择自己有写入权限的位置，并按实际目录修改。

## 1. 创建并进入学习目录

```powershell
New-Item -ItemType Directory -Path C:\dev\wails-learning -Force
Set-Location C:\dev\wails-learning
Get-Location
```

`New-Item` 创建文件夹，`Set-Location` 切换位置，`Get-Location` 查看当前位置。[创建目录](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/new-item), [切换目录](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/set-location), [查看位置](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-location)

## 2. 创建子目录并查看内容

```powershell
New-Item -ItemType Directory -Path .\notes -Force
Get-ChildItem
```

点表示当前目录。在本例中，`notes` 位于学习目录下。`Get-ChildItem` 列出当前目录的内容。[目录列表说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-childitem)

## 3. 进入子目录，再返回上一级

```powershell
Set-Location .\notes
Get-Location
cd ..
Get-Location
```

`cd` 是切换目录的常用简写，两个点表示上一级目录。每次切换后，可以再查看位置确认结果。

## 4. 路径带空格时使用引号

```powershell
New-Item -ItemType Directory -Path "C:\dev\My Wails Project" -Force
Set-Location "C:\dev\My Wails Project"
Get-Location
```

用英文双引号包含整条路径，使带空格的路径作为一个完整参数传入。[PowerShell 引号规则](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_quoting_rules)

## 5. 用编辑器创建并保存文本

回到学习目录，在编辑器中打开整个文件夹。

```powershell
Set-Location C:\dev\wails-learning
```

新建 `lesson.txt`，输入下面的一行文字。

```text
今天学会了查看位置、切换目录和保存文件。
```

确认文件位置和扩展名，在状态栏检查编码为 UTF-8，按 `Ctrl+S` 保存。[VS Code 文件编码支持](https://code.visualstudio.com/docs/editing/codebasics#_file-encoding-support)

## 6. 在终端验证保存结果

```powershell
Set-Location C:\dev\wails-learning
Get-ChildItem
Get-Content .\lesson.txt -Encoding utf8
```

显式指定 `-Encoding utf8`，让文件按 UTF-8 解码。Windows PowerShell 与较新 PowerShell 的默认编码行为存在差异，读取练习文本时保留这个参数。[读取文件](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/get-content?view=powershell-5.1), [字符编码说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_character_encoding?view=powershell-5.1)

## 7. 两个快捷键

| 当前窗口 | 快捷键 | 用途 |
| --- | --- | --- |
| 正在运行开发命令的终端 | `Ctrl+C` | 中断当前命令 |
| 编辑器 | `Ctrl+S` | 保存正在编辑的文件 |

## 本章完成标准

- 能查看当前目录并列出其中内容。
- 能进入 `notes` 子目录并返回学习目录。
- 能正确使用带空格的路径。
- 能创建并保存 UTF-8 文本，并在终端中读取它。

视频中的终端和编辑器为操作示意，自己的实际路径与窗口界面以电脑显示为准。
