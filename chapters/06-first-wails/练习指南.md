# 第 6 章练习指南 · 运行第一个 Wails 项目

本章把前面的 Go 与网页基础放进真实桌面窗口，完成创建项目、启动、修改 Go 问候和修改 HTML 标题四个步骤。示例使用 Wails CLI v3.0.0 的 `vanilla-js` 模板。

## 1. 创建一个新项目

先进入自己的学习目录。下面沿用前面章节的示例位置。

```powershell
Set-Location C:\dev\wails-learning
Get-Location
wails3 init -n first-wails -t vanilla-js -mod example.com/learn/first-wails
Set-Location first-wails
wails3 dev
```

按自己的实际目录修改第一条命令。创建命令会建立 `first-wails` 项目文件夹。已有同名练习目录时，可以进入现有项目继续，或者选择另一个学习位置创建新项目。[首个应用教程](https://v3.wails.io/quick-start/first-app/)

| 参数 | 本章的值 | 用途 |
| --- | --- | --- |
| `-n` | `first-wails` | 设置项目名称 |
| `-t` | `vanilla-js` | 选择原生 JavaScript 与 Vite 模板 |
| `-mod` | `example.com/learn/first-wails` | 指定 Go 模块路径 |

模块路径也会影响自动生成绑定的导入位置。模板名称显式使用 `vanilla-js`，可以和本课程的 `main.js` 文件对应。[CLI 参数说明](https://v3.wails.io/guides/cli/)

## 2. 第一次启动时观察什么

`wails3 dev` 持续运行，准备依赖、生成绑定、编译应用，并启动开发窗口。第一次准备需要一些时间，观察终端输出，等窗口出现。[开发启动说明](https://v3.wails.io/quick-start/first-app/)

在默认模板中输入 `小明`，点击 `Greet`，本机实测返回 `Hello 小明!`。当前模板会把结果放进右上角的短暂提示中，也会更新页面中的姓名显示。

开发命令应在项目根目录执行。这个目录里能够找到 `go.mod` 和 `Taskfile.yml`。

## 3. 常用文件位置

```text
first-wails/
  main.go
  greetservice.go
  go.mod
  go.sum
  Taskfile.yml
  build/
  frontend/
    index.html
    src/main.js
    public/style.css
    package.json
    package-lock.json
    vite.config.js
    bindings/
    dist/
  bin/
```

`main.go` 创建应用、注册服务和创建窗口。`greetservice.go` 实现问候服务。`frontend/index.html` 是页面入口，`frontend/src/main.js` 负责交互和服务调用，`frontend/public/style.css` 设置外观。[项目结构说明](https://v3.wails.io/guides/dev/project-structure/)

`bindings` 是生成的前端绑定，`dist` 是前端构建产物，`bin` 是应用构建产物。编辑功能时修改源文件，再通过开发或构建命令生成产物。[首个应用与构建说明](https://v3.wails.io/quick-start/first-app/)

## 4. 替换 Go 问候服务

打开 `greetservice.go`，用以下完整内容替换并保存。

```go
package main

import (
    "fmt"
    "strings"
)

type GreetService struct{}

func (g *GreetService) Greet(name string) (string, error) {
    name = strings.TrimSpace(name)
    if name == "" {
        return "", fmt.Errorf("请输入姓名")
    }
    return "你好，" + name + "！欢迎学习 Wails v3。", nil
}
```

`TrimSpace` 去掉首尾空白，`(string, error)` 同时返回字符串和错误，`nil` 表示这里没有错误。服务已在 `main.go` 中通过 `application.NewService(&GreetService{})` 注册。[Wails 服务说明](https://v3.wails.io/features/bindings/services/)

保存 Go 文件后，观察终端中的重新编译，等待应用重启。输入 `小明` 并点击，实测得到 `你好，小明！欢迎学习 Wails v3。`。Go 源码变化会触发自动构建和重启。[开发工作流程](https://v3.wails.io/guides/dev/workflow/)

这版默认前端会把完全空的输入改成 `anonymous`，服务调用错误则记录到控制台。只有空格的字符串会交给 Go 检查。服务返回错误后，错误的界面展示由前端的 `catch` 处理方式决定。配套工程沿用模板的处理方式，后续实战会进一步组织界面反馈。

## 5. 修改页面的主要标题

打开 `frontend/index.html`，在 `h1` 内找到下面这一段。

```html
<span class="title-accent">Wails +</span>
```

把里面的文字改成课堂标题。

```html
<span class="title-accent">Wails 课堂 ·</span>
```

保存后，窗口中的页面标题会更新。保留原来的 `span` 与周围元素结构，模板已有的姓名切换交互仍然可以继续工作。

本步骤修改的是页面中的主要标题。窗口标题栏的文字由 `main.go` 中的窗口配置控制，本章保留模板中的 `Window 1`。

## 6. 对应两类修改的结果

| 修改位置 | 观察过程 | 验证结果 |
| --- | --- | --- |
| `greetservice.go` | 编译 Go，应用重启 | 点击后得到新的中文问候 |
| `frontend/index.html` | 开发页面更新 | 页面出现“Wails 课堂” |

两类变化都由持续运行的开发模式协调。修改后先保存，再查看终端反馈和窗口结果。[开发命令说明](https://v3.wails.io/guides/cli/)

## 7. 运行配套完整工程

配套工程位于本章的 `project/first-wails` 文件夹，已经包含上述两处修改。从本章目录执行。

```powershell
Set-Location .\project\first-wails
wails3 dev
```

开发和构建命令会重新生成所需的依赖、绑定和构建产物。制作环境使用 Wails CLI v3.0.0、Go 1.27.0、Node.js v24.19.0 和 Vite 8.3.7，项目模块声明 Go 1.26.0，具体依赖版本记录在 `go.mod`、`go.sum` 与 `package-lock.json` 中。

## 8. 本章检查与停止运行

独立完成以下操作。

1. 在项目根目录运行 `wails3 dev`，看到真实桌面窗口。
2. 修改 Go 的问候内容，保存后等待重编译和重启。
3. 修改 HTML 的页面标题，保存后观察页面更新。
4. 说清楚服务逻辑、页面结构和交互脚本分别放在哪里。

练习结束，在运行开发命令的终端按 `Ctrl+C`。下次进入同一个项目目录，再运行 `wails3 dev` 继续练习。

启动或更新不符合预期时，先检查项目目录、工具是否可调用、文件是否已保存，再阅读终端中的错误信息。
